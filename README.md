# WattSaver

This project proposes an AI-based web application to help households predict their monthly electricity consumption and bills while providing practical energy-saving recommendations. Motivated by the lack of public awareness and education on electricity usage in Indonesia, where consumption growth (7% annually) far exceeds global averages

- Demo video : https://www.youtube.com/watch?v=2eJlqyQLaU0
---
- The application leverages household and electronic device data to deliver accurate predictions.
- Using machine learning models : Random Forest(after evaluate Random Forest Classifier (RF), Decision Tree Classifier (DT),Support Vector Classifier (SVC), Logistic Regression (LR), XGBoost Classifier (XGB)) which have shown up to 98.3% accuracy in electricity consumption classification
- This solution aims to encourage energy-efficient behavior, reduce consumerist usage patterns, and promote energy awareness in support of smarter, sustainable cities.
